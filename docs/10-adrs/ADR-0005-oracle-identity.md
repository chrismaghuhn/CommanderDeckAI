# ADR-0005-oracle-identity — Oracle-ID als kanonische Spielidentität

**Status:** Accepted<br>
**Datum:** 2026-08-10


## Entscheidung

Training/Decklogik verwendet Oracle-Identität; konkrete Printings sind separate Entitäten.

## Begründung

Reprints sollen dieselbe Spielkarte repräsentieren, Preise/Sammlungen benötigen trotzdem Printings.

## Folgen

Singleton-/Name-Ausnahmen bleiben Ruleset-Verantwortung. Export wählt später ein Printing.
