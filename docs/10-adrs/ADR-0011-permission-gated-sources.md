# ADR-0011-permission-gated-sources — Unklare Quellen bleiben technisch deaktiviert

**Status:** Accepted<br>
**Datum:** 2026-08-10


## Entscheidung

Archidekt, Moxfield, EDHREC und ähnliche Quellen werden ohne dokumentierte Freigabe nicht bulk-ingestiert.

## Begründung

Öffentliche Sichtbarkeit ist keine pauschale Scraping-/Redistributionslizenz.

## Folgen

User-Export oder schriftliche/Terms-basierte Erlaubnis kann später einen Adapter freischalten.
