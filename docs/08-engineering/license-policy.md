# Projektlizenz und NOTICE-Policy

## Empfohlener Default

Für selbst geschriebenen Code ist MIT ein einfacher Default für ein kleines Open-Source-Forschungsprojekt. Die endgültige Wahl bleibt vor dem ersten öffentlichen Release eine bewusste Repository-Entscheidung.

## Strikte Trennung

- Code-Lizenz deckt nicht automatisch Fremddaten ab;
- Datasetmanifeste führen Source-/Redistributionsstatus;
- Modellrelease dokumentiert Trainingsquellen und zulässige Weitergabe;
- Kartenbilder werden nicht benötigt und nicht gebündelt;
- Marken-/Fan-Content-Hinweis steht im NOTICE/README;
- API-spezifische Attributionen werden sichtbar ergänzt.

Ein `LICENSE`-File wird erst nach bewusster Auswahl in den echten Repository Root übernommen; das Designpaket enthält deshalb nur ein NOTICE-Blueprint.
