# M1 — Card Catalog und Ruleset

## Ziel

Versionierter Kartenkatalog und unabhängiger Commander-Legalitätsdienst.

## Deliverables

- Scryfall-Bulk-Adapter;
- optional ergänzender MTGJSON-Adapter;
- Canonical Card/Printing Mapping;
- Ruleset-Snapshot-Builder;
- Candidate-Pool-Filter;
- Deckvalidator;
- Golden-/Property-Tests für Command Zone, Color Identity, Copy Limits und Banlist.

## Exit-Kriterien

- Cards/Ruleset vollständig manifestiert;
- bekannte Sonderfälle getestet;
- keine Legalität aus ML-/Deckhäufigkeiten;
- historischer Ruleset-Snapshot reproduzierbar;
- unbekannte Karten führen zu klaren Fehlern.
