# Harte Constraints

## Format/Legalität

- Gesamtgröße gemäß Ruleset, typischerweise 100 inklusive Command Zone;
- zulässige Command-Zone-Kombination;
- Color Identity;
- Ban-/Sonderlisten;
- Copy Limits und kartenspezifische Ausnahmen;
- keine Token/Digital-only-Karten, sofern Profil dies ausschließt;
- Zonenregeln und Companion-Sonderfälle.

## Nutzer

- Must-Include;
- Must-Exclude;
- Collection-only;
- maximales Budget mit definiertem Preis-Snapshot;
- harte Rollen-Minima/Maxima;
- Landbereich;
- erlaubte Sets/Release-Cutoff;
- verbotene Mechaniken oder Kartenlisten.

## Regel

Harte Constraints werden niemals still zu Soft Constraints. Bei Konflikt gibt der Optimizer `INFEASIBLE` mit einem erklärbaren Konfliktkern oder schrittweiser Diagnose zurück.
