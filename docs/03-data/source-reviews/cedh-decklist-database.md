# cEDH Decklist Database assessment

**Status:** `RED` for automatic acquisition; research-only

| Question | Assessment |
| --- | --- |
| Data type | Curated cEDH decklists, archetype metadata, and links to external deck content. |
| Official API or bulk access | A repository or public page is not by itself an approved bulk/API contract. No project-approved machine-readable acquisition path is recorded. |
| Authentication | No approved credentialed path is configured. |
| Rate limits and robots | Current repository/site guidance and robots rules must be checked before any permitted access. Do not clone or crawl beyond documented permission. |
| License and ToS | The license of each repository revision and the rights for linked or contributed deck content must be reviewed separately. |
| Redistribution | Not approved for automatic raw or derived redistribution. |
| Attribution | Required wording is not established; preserve source attribution for any explicitly permitted manual use. |
| Local storage | Manually reviewed metadata, user-provided exports, or a separately permitted repository snapshot only. |
| Recommended use | Small, manually reviewed reference/benchmark fixtures; not an automatic training feed. |

The repository may be useful as a research reference, but public availability
does not override the source-approval gate.
