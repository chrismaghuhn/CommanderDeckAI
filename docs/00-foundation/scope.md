# Scope

## Initial

- offizielles Commander-Deckformat mit versioniertem Ruleset;
- ein oder mehrere Karten in der Command Zone;
- Teildeck-Completion;
- Ranking legaler Kandidaten;
- vollständige Deckauswahl unter Constraints;
- manuelle Deckimporte, offizielle Precons und freigegebene APIs;
- Offline-Benchmarks;
- CLI und Dateien als primäre Schnittstellen.

## Später

- cEDH-Pod-Outcome-Reranking;
- zeitabhängige Meta-Features;
- Budget-/Printing-Auswahl;
- Mana-Base-Optimierung;
- Forge-Batch-Evaluation;
- Human-Pairwise-Evaluation für Casual;
- lokale oder gehostete API als Adapter.
