# Benchmark-Suite

## B1 — Completion Standard

Zeitlicher Holdout, bekannte Commanders, zufällige und strukturierte Masken.

## B2 — Cold Commander

Command-Zone-Kombination im Training nicht vorhanden. Misst strukturierte Generalisierung.

## B3 — New Card Window

Karten nach Trainings-Cutoff; nur Modelle mit strukturierten Features können sinnvoll ranken.

## B4 — Precon Holdout

Offizielle Deckprodukte als kleine, saubere Referenzmenge.

## B5 — cEDH Temporal

Spätere Events, vollständig eventgruppiert.

## B6 — Optimizer Constraint Suite

Synthetische und reale Requests für Legalität, Budget, Rollen und Infeasibility.

## B7 — Human Pairwise Casual

Später: zwei Deck-/Recommendation-Ausgaben werden unter klarer Nutzerabsicht verglichen. Keine freie 1–10-Powerbewertung.
