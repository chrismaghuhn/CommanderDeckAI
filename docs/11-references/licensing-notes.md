# Lizenz- und Terms-Hinweise

## Code vs. Daten

Eine Open-Source-Lizenz eines Adapters oder Repositories überträgt nicht automatisch Rechte an allen von ihm referenzierten Decklisten, Kartentexten, Bildern oder Nutzerdaten.

## Sichere Defaultposition

- Projektcode kann separat lizenziert werden;
- Scryfall/MTGJSON/Spellbook-Nutzung gemäß jeweiliger Bedingungen und Attribution;
- TopDeck-/Spicerack-API-Pflichten in Config und Export sichtbar machen;
- EDHREC/Archidekt/Moxfield nicht bulk-scrapen, bis ein belastbarer erlaubter Pfad dokumentiert ist;
- keine Kartenbilder im Trainingsdataset erforderlich;
- öffentliche Dataset-Releases nur aus Quellen mit expliziter Redistribution-Freigabe.

## Fan Content/Marken

Projektbeschreibung soll klarstellen, dass es ein inoffizielles Fan-/Research-Projekt ist und nicht von Wizards of the Coast unterstützt wird. Marken- und Fan-Content-Regeln sind vor öffentlichem Branding erneut zu prüfen.

Diese Datei ist keine Rechtsberatung.
