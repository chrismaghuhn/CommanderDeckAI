# Terms-Review-Checkliste

Für jede Quelle als eigene Review-Datei ausfüllen:

```yaml
source_id:
reviewed_at:
reviewer:
official_docs:
terms_url:
access_method:
auth_required:
rate_limit:
attribution:
raw_local_storage:
normalized_local_storage:
redistribution_raw:
redistribution_derived:
personal_data_fields:
required_deletions:
user_agent_requirement:
contact_or_permission_reference:
approval_status:
next_review_due:
notes:
```

## Re-Review-Auslöser

- API-Version ändert sich;
- Terms/Privacy-Seite ändert sich;
- Source verlangt neue Authentifizierung;
- Datenfelder enthalten plötzlich PII;
- geplanter öffentlicher Dataset-/Modelrelease;
- Adapter wechselt von User-Export zu Bulk-Abruf.
