# Planning-Artefakte

- `backlog.csv`: issue-große, abhängige Implementierungsschritte;
- `acceptance-matrix.csv`: milestoneübergreifende Releasekriterien.

Die CSVs sind bewusst toolneutral und können in GitHub Projects, Linear oder ein Spreadsheet importiert werden. Ein Issue wird erst gestartet, wenn seine `depends_on`-Einträge abgeschlossen sind.
